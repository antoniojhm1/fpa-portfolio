# Caddie Social — "Make the Turn" campaign

Launch ad campaign for the Caddie Social rope hat, built to be produced in [Buzzy AI](https://www.buzzy.now/).

Open `index.html` for the full kit:

- Brief: audience, single message, tone
- Product lock: a prompt block to append to every Buzzy prompt so the logo and colors don't drift
- 4 ads with copy-ready Buzzy prompts (Product → Scene → Video) and ad copy
  1. Make the Turn — 30s hero film
  2. "Group chat said rope hats" — UGC conversion ad
  3. Clubhouse poster set — 3 statics incl. holiday gifting
  4. Tee-box spin — 6s bumper
- 4-week flight plan (example $3,000 test budget) and KPI targets
- Production checklist

`assets/` holds the product reference photos to upload to Buzzy.
